# 인게임 아트 가이드

인게임 배경과 캐릭터 그림을 새로 만들거나 고칠 때 따르는 기준이다. 표지(홈 화면) 그림은 대상이 아니다.
모든 그림은 이미지 생성 모델(Codex 구독 계정)로 만들고, 코드로 그리지 않는다.

## 화풍

- 일본 애니메이션풍 수채화 일러스트. 가는 잉크 윤곽선, 부드럽게 번지는 수채 질감, 종이 결이 살짝 보임
- 기준 화풍: 표지 히로인(`public/img/her_home_v1.webp`)과 같은 선 굵기, 채색, 눈 표현
- 색감: 따뜻한 노을빛(주황·분홍)과 청록 바다색 대비, 채도 중간. 과포화·네온 금지
- 조명: 한 방향의 부드러운 빛, 은은한 그림자, 먼 배경은 살짝 흐리게
- 금지: 글자, 로고, 워터마크, 말풍선, 프레임, 서명, 사진풍·3D 렌더풍

## 캐릭터 고정 설정

장면마다 의상은 바뀌어도 얼굴·머리·눈은 바꾸지 않는다. 새 그림은 아래 캐릭터 시트를 참조 이미지로 넣어 생성한다.

| 캐릭터           | 고정 설정                                                                                 | 시트                                                  |
| ---------------- | ----------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| 히로인 이수정    | 20대 초반, 허리까지 오는 검은 생머리(살짝 웨이브), 눈썹을 덮는 앞머리, 청회색 눈, 흰 피부 | [`docs/art/sheet_sujung.webp`](art/sheet_sujung.webp) |
| 주인공(플레이어) | 20대 초반 남성, 짧은 흑발, 귀를 살짝 덮는 옆머리, 갈색 눈, 검은 셔츠 또는 어두운 재킷     | [`docs/art/sheet_player.webp`](art/sheet_player.webp) |

## 파일 규격

화면 구조([DESIGN-SYSTEM.md](DESIGN-SYSTEM.md)의 화면 층 구조)가 이 규격을 전제로 한다.

| 종류               | 파일 이름          | 생성 크기      | 배경   | 저장 형식                        |
| ------------------ | ------------------ | -------------- | ------ | -------------------------------- |
| 장소 배경          | `bg_<장소>_main`   | 1536×1024      | 불투명 | webp q78, 원본 크기              |
| 장면 캐릭터        | `bg_<장소>_<장면>` | 1024×1536 세로 | 투명   | webp q78·alpha q85, 긴 변 1152px |
| 인트로·엔딩 캐릭터 | `her_*`, `mc_*`    | 1024×1536 세로 | 투명   | 위와 같음                        |

- 캐릭터는 **허리 위 세로 구도**이고 그림 아래 끝이 캔버스 아래 끝에 닿아야 한다. 화면이 캐릭터를 아래에 붙여 그리므로, 아래에 빈 공간이 있으면 캐릭터가 떠 보인다
- 파일 이름은 기존과 같게 둔다. 스토리 데이터(`src/data/stories/`)와 엔딩 화면이 이 이름으로 그림을 부른다
- 변환: `cwebp -q 78 -alpha_q 85 -m 6 [-resize <폭> <높이>] 원본.png -o public/img/<이름>.webp`
