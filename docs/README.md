## 어디에 무엇을 쓸 것인가

새로 쓸 내용이 생겼을 때 다음 순서로 판단한다.

1. **아직 결정되지 않은 설계인가** → `superpowers/specs/`에 스펙으로 쓴다
2. **결정된 실행 순서인가** → `superpowers/plans/`에 계획으로 쓴다
3. **확정된 규칙·구조인가** → 위 표에서 해당 주제 문서에 쓴다
4. **AI 에이전트의 작업 절차인가** → 루트 [`claude.md`](../claude.md)에 쓴다

## 문서가 코드와 어긋나지 않게 하는 규칙

이 문서 체계가 만들어진 계기는 기존 `claude.md`가 **존재하지 않는 라우트**(`/login`, `/signup`)를
기술하고 있었던 것이다. 문서가 틀리면 없느니만 못하다.

- 파일 경로를 언급할 때는 백틱으로 감싼다 (`` `src/utils/auth.js` ``). 자동 검증 대상이 된다
- **아직 존재하지 않는 파일**은 전체 경로를 백틱으로 감싸지 않는다. 검증에 걸린다.
  대신 "`logger.js` (Phase 1에서 `src/utils/`에 생성 예정)" 형태로 쓴다
- 구조를 바꾸는 PR은 관련 문서를 같은 PR에서 갱신한다
